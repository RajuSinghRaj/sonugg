# Videos Directory

Place your 3 video clips of Sonuuuuuuuu ggggg in this directory with the exact filenames:
- video1.mp4
- video2.mp4
- video3.mp4

Features for mobile phone compatibility & automatic looping:
- Videos use `autoplay`, `muted`, `loop`, and `playsinline` so they play automatically in a smooth loop inside the polaroid card frame when scrolled into view on mobile (iOS & Android) and desktop!
- If a video file is not added yet, an elegant paper-style video placeholder card with a play icon and instructions will be shown cleanly.
