# Audio Directory

Place your Raksha Bandhan background song MP3 file in this directory with the exact name:
- rakhi-song.mp3

Features:
- **Infinite Looping**: The song is set to `loop` infinitely with no ending.
- **Automatic Autoplay**: Audio starts automatically when the site opens or on the very first touch/tap anywhere on screen (complying with mobile browser audio autoplay policies).
- **Graceful Fallbacks**: If the song is not added yet, the floating button gently displays a notification explaining where to put `rakhi-song.mp3` without throwing any JavaScript errors.
